04RULES

RULES &GUIDELINES

大会ルール・注意事項

01参加規約+

第1条｜大会概要
1. 本大会は、Nidmegent Esports（以下「運営」といいます。）が主催するVALORANTコミュニティカスタムイベント「NID CUSTOM」（以下「本大会」といいます。）です。
2. 本大会は、VALORANTプレイヤー同士の交流および競技を目的として、原則として毎月開催します。
3. 本大会はRiot Games, Inc.およびVALORANT Esportsが主催、運営、承認、スポンサーする公式大会ではありません。
4. 本大会は、Riot Gamesが定めるVALORANTの利用規約、コミュニティー大会ガイドラインその他関連する規約・ポリシーを遵守して運営します。

第2条｜参加資格
1. 本大会への参加には、以下の条件を満たす必要があります。
・VALORANTの正規アカウントを所持していること
・Riot GamesおよびVALORANTの利用規約に違反していないこと
・本大会の規約および運営からの指示に同意すること
・大会運営上必要な連絡手段を確保していること
2. 年齢その他の参加条件については、各開催回の募集要項に別途定める場合があります。
3. 運営が参加を不適切と判断した場合、参加をお断りする場合があります。

第3条｜エントリー
1. 本大会への参加を希望するチームは、運営が指定する方法によりエントリーを行うものとします。
2. エントリー時に虚偽の情報を登録した場合、参加資格を失う場合があります。
3. エントリー後のメンバー変更については、運営が定める期限および方法に従うものとします。
4. エントリー数が運営上必要な人数に満たない場合、運営の判断により大会を中止または延期する場合があります。
5. 中止・延期等が決定した場合、運営は可能な限り速やかに参加者へ告知します。

第4条｜大会形式
< 1. 大会形式、参加チーム数、試合数、勝利条件、マップ、サーバーその他の詳細は、各開催回の大会概要にて告知します。
2. 大会形式は開催回によって変更される場合があります。
3. 試合開始時刻および集合時刻は、各開催回の案内に従うものとします。
4. 運営上必要な場合、運営は大会形式を変更することがあります。

第5条｜試合ルール
1. 試合は、原則として大会当日時点で提供されているVALORANTのゲーム環境を使用します。
2. 使用マップ、モード、サーバー、BAN/PICK等の詳細は、各開催回の大会概要またはDiscord等で告知します。
3. 試合中に発生した問題については、原則として運営の判断を最終決定とします。
4. 運営から再試合、試合停止、試合結果の修正その他の指示があった場合、参加者はこれに従うものとします。

第6条｜遅刻・欠場・棄権
1. 指定された集合時刻までに参加確認ができない場合、運営は当該チームを失格とすることがあります。
2. 試合開始後に参加者が不足した場合、運営の判断により試合を開始または不戦敗とする場合があります。
3. 無断欠場や故意の遅刻を繰り返すチームについては、以降のNID CUSTOMへの参加を制限する場合があります。
4. やむを得ない事情による欠場については、可能な限り事前に運営へ連絡してください。

第7条｜ゲームの切断・通信障害
1. 試合中にプレイヤーがゲームから切断された場合、運営は状況を確認したうえで対応を決定します。
2. 個人の通信環境、PC環境、周辺機器等に起因する問題について、原則として運営は責任を負いません。
3. サーバー障害、ゲーム側の不具合、重大な通信障害等が発生した場合、運営の判断により再試合、試合延期、試合結果の確定等を行う場合があります。
4. 障害発生時の対応については、参加者間で独自に判断せず、運営の指示に従ってください。

第8条｜禁止事項
参加者は、以下の行為を行ってはなりません。

1. チート、ハック、マクロ、スクリプトその他不正な外部ツールを使用する行為
2. ゲームの不具合やバグを意図的に利用する行為
3. ゴースティング、スナイプ、故意の情報漏洩その他の不正な情報取得を行う行為
4. アカウントの貸与、譲渡、共有または第三者による使用
5. なりすまし、虚偽情報の申告その他の不正行為
6. 試合結果を意図的に操作する行為
7. 他の参加者、運営、観戦者等に対する誹謗中傷、脅迫、差別、嫌がらせその他の迷惑行為
8. 運営の指示に従わない行為
9. 本大会またはNidmegent Esportsの信用を著しく損なう行為
10. その他、運営が本大会の趣旨に反すると判断する行為

第9条｜不正行為への対応
1. 運営が不正行為または規約違反を確認した場合、以下の措置を行うことがあります。

・警告
・試合の敗北
・当該試合または大会からの失格
・大会への参加停止
・今後のNID CUSTOMへの参加禁止
2. 悪質な行為については、事前の警告なく失格等の措置を行う場合があります。
3. 不正行為の判断に必要な場合、運営は参加者へ画面共有、録画、スクリーンショットその他の情報提供を求めることがあります。

第10条｜チャット・コミュニケーション
1. Discord等、本大会で指定するコミュニケーションツールを使用する場合、各サービスの利用規約および運営の指示に従うものとします。
2. 暴言、差別的発言、過度な煽り、嫌がらせ、スパムその他コミュニティの秩序を乱す行為は禁止します。
3. 運営が不適切と判断した発言については、削除、警告、退出その他必要な措置を行う場合があります。

第11条｜配信・大会映像
1. 本大会では、運営または参加者による試合配信・動画投稿等を行う場合があります。
2. 参加者は、本大会への参加をもって、試合映像、配信映像、スクリーンショット等が本大会の運営・広報目的で使用される場合があることに同意するものとします。
3. 参加者自身が配信を行う場合は、ゲーム内の規約、配信プラットフォームの規約および関係するガイドラインを遵守してください。
4. 運営は、参加者の配信を妨害または制限するものではありません。ただし、大会運営上必要な場合は対応を求めることがあります。

第12条｜SNS・広報
1. 運営は、本大会に関する情報を公式SNS、Webサイト、Discordその他の媒体で公開する場合があります。
2. 大会結果、チーム名、選手名、順位、試合結果等は、大会運営および広報を目的として公開する場合があります。
3. 参加者が本大会に関する情報をSNS等へ投稿する場合は、他の参加者や運営への誹謗中傷、虚偽情報の拡散等を行わないものとします。

第13条｜個人情報の取り扱い
1. 運営は、大会運営に必要な範囲で参加者から提供された情報を取り扱います。
2. 取得した情報は、以下の目的で使用します。

・大会の運営・連絡
・参加者確認
・大会結果の公開
・不正行為・規約違反への対応
・本大会およびNidmegent Esportsに関する必要な連絡
3. 運営は、法令に基づく場合を除き、取得した個人情報を大会運営に必要な範囲を超えて第三者へ提供しません。

第14条｜大会の中止・延期
1. 以下の場合、運営は本大会を中止、延期または内容変更することがあります。

・参加チーム数が十分でない場合
・ゲームまたはサーバーに重大な障害が発生した場合
・災害、停電、通信障害その他の不可抗力が発生した場合
・運営上やむを得ない事情がある場合
・その他、運営が開催困難と判断した場合
2. 大会の中止または延期が決定した場合、運営は可能な限り速やかに参加者へ告知します。

第15条｜運営による裁定
1. 大会中に発生したトラブル、規約に明記されていない事項および規約の解釈については、運営が最終的に判断します。
2. 運営は、公平な大会運営を行うため、状況に応じて個別に裁定を行うことがあります。
3. 運営による裁定について、参加者は原則としてこれに従うものとします。

第16条｜免責事項
1. 運営は、参加者の通信環境、PC、周辺機器、ゲームアカウントその他参加者側の環境に起因する問題について責任を負いません。
2. ゲームのアップデート、不具合、サーバー障害等により発生した損害について、運営は責任を負いません。
3. 参加者同士のトラブルについては、原則として当事者間で解決するものとします。ただし、大会運営に影響する場合、運営が必要な措置を講じることがあります。

第17条｜規約の変更
1. 運営は、必要に応じて本規約を変更することがあります。
2. 規約を変更した場合は、公式サイト、Discord、SNS等を通じて告知します。
3. 変更後の規約は、運営が別途指定する場合を除き、告知した時点から適用されます。

第18条｜Riot Gamesとの関係
1. NID CUSTOMは、Nidmegent Esportsが独自に運営するコミュニティイベントです。
2. Riot Games, Inc.、Riot GamesおよびVALORANT Esportsが本大会を主催、運営、承認、推奨またはスポンサーしていることを示すものではありません。
3. 本大会は、Riot Gamesが定める最新のVALORANTコミュニティー大会ガイドライン、サービス規約その他の関連ポリシーに従って運営します。
4. Riot Games側の規約・ガイドラインが変更された場合、本大会の規約や運営方法を変更する場合があります。

・VALORANTに関する注意事項
NID CUSTOMはRiot Games, Inc.またはVALORANT Esportsが運営する公式大会ではありません。
VALORANTおよび関連する知的財産は、Riot Games, Inc.の所有物です。
NID CUSTOMは、Riot Gamesが定める最新のコミュニティー大会ガイドラインおよび関連規約を遵守して運営します。
